# Security Reports

Do not open a public issue or discussion for a suspected vulnerability, leaked
credential, private transcript or personal-data exposure.

Use this repository's **Security -> Report a vulnerability** page; the report
stays private between you and the maintainers.

Include the affected version, deployment mode, the smallest synthetic
reproduction, impact and redacted diagnostics. Never send your full archive,
identity file, secret configuration, model-provider keys or other people's cards.

Reports go to the repository owner before any triage decision or public
disclosure. Security fixes are made on the latest release.
